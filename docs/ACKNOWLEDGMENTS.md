# Acknowledgments

Rakitsu draws inspiration from the following works and authors:

## Research

- **Tim Kräuter** — "The Visual Debugger Tool," ICSME 2022.
  Design inspiration for the visual debugger: minimizing node movement between updates, configurable visualization depth, and layout strategies.
  Artifact: https://github.com/timKraeuter/ICSME-2022

## Books

- **Antonio Gulli** — "Agentic Design Patterns: A Hands-On Guide to Building Intelligent Systems."
  Foundational reference for multi-agent orchestration patterns and agentic system design.

- **Salvatore Raieli & Gabriele Iuculano** — "Building AI Agents with LLMs, RAG, and Knowledge Graphs: A practical guide to autonomous and modern AI agents" (Packt Publishing, 2025).
  Foundational reference for the brain/perception/action agent framing and knowledge-graph-backed memory concepts.

## Open Source

- **Zep — Graphiti.**
  The supersede/retire knowledge lifecycle and current-view-by-default recall in rakitsu's native memory are concept-level inspirations from Graphiti's bi-temporal model (concept only, no code shared). The valid_at/invalid_at/expired_at scheme itself follows classic temporal-database practice.
  Repo: https://github.com/getzep/graphiti

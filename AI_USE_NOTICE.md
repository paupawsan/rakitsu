# AI Use Notice

Supplementary signal to readers of this codebase regarding AI tools. The
binding legal terms are in [LICENSE](./LICENSE). This file is plain-English
explanation of how AI tooling interacts with those terms.

## How this project itself is built

Honesty first: Rakitsu is co-developed with AI. A human rights-holder sets
direction, reviews every change, and verifies every release; AI coding
assistants carry out a substantial share of the implementation. This notice
asks others to be straightforward about AI use on this codebase, so it
starts by being straightforward about our own.

## Permitted

- **Read** the code with any tool, AI-assisted or not. Public source is
  public source.
- **Learn** from the design — concepts, patterns, architectural choices.
  Copyright covers expression, not ideas; we cannot legally restrict
  understanding.
- **Personal study and experimentation** by individual developers,
  including using AI coding assistants (Claude Code, Cursor, GitHub
  Copilot, local LLMs, etc.) on a local clone for your own purposes.
- **Authors' own use**: the rights-holders explicitly retain full
  freedom to use any AI tooling on this codebase.

## Prohibited

The following are **derivative-work activities** subject to whatever
license terms govern this repository:

- Shipping a hosted, embedded, or distributed product or service in
  this project's product space (visual agent design / multi-agent
  composition / agent debugging / time-travel inspection / agent
  runtime / IDE for AI agents). The license has a non-compete clause
  for exactly this reason.
- Using AI-accelerated reverse-engineering as a shortcut to bypass
  license terms. AI-assisted reimplementations remain derivative works
  bound by the same terms as hand-coded reimplementations. The license
  doesn't care HOW the competitor was built; it cares that they're
  competing.
- Bulk ingestion into commercial AI training datasets without explicit
  written permission from the rights-holders.

## Why this notice exists

AI tools accelerate the path from "read someone's code" to "ship a
similar product." That isn't new — humans could always do it slowly —
but the timeline is shorter now. This notice is a signal that the
license's existing protections apply to AI-accelerated activity
exactly as they apply to manual activity.

## What this notice cannot do

- Stop hostile actors who ignore signals and licenses (impossible)
- Detect violations after the fact
- Prevent anyone from understanding the design and rebuilding from
  scratch with novel code (that's just normal software competition)

## Questions

If you're unsure whether an intended use is permitted, the safe answer
is "ask the rights-holders." Listed in [LICENSE](./LICENSE).
